## Rincian Tugas

### tugas3.py – Python Basics
- Deklarasi variabel dengan 5 tipe data berbeda (string, integer, float, boolean, list).
- Manipulasi string: `len()`, `.upper()`, `.lower()`, penggabungan string.
- Operasi matematika dasar: `+`, `-`, `*`, `/`, `//`, `%`.
- Akses dan manipulasi list: `append()`, `remove()`, `pop()`.
- Input interaktif dari user dengan `input()`.

### tugas4.py – Python Data Structures
- **List**: akses elemen, slicing `[start:stop:step]`, `append()`, `insert()`, `extend()`, `pop()`, `remove()`.
- **Tuple**: panjang (`len()`), akses indeks, unpacking dengan `*rest`.
- **Set**: operasi himpunan `|`, `&`, `-`, `^`; pembuktian duplikat otomatis hilang.
- **Dictionary**: tambah/ubah/hapus key, iterasi `.items()`, `.keys()`, `.values()`.
- **Nested structures**: list of dict, loop, dan list comprehension filter.
- **Comprehension**: list, dict, dan set comprehension.
- **Keanggotaan**: pengecekan `in`, `index()`.

### tugas5.py – Python Function and Class
- Functions: `greet()`, `tambah()`, `rata_rata()`.
- Class `Student` dengan atribut dan method: `tambah_nilai()`, `rata_nilai()`, `status()`, `__str__()`.
- Demo di blok `if __name__ == "__main__"`.
